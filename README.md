# RISC-V SoC IP Development Project

This repository contains my work for the VSD RISC-V IP development program.
It includes environment setup, basic IP design, multi-register peripherals,
and a real SPI peripheral IP.

---

## Project Structure

- **Task-1:** Environment Setup & RISC-V Reference Bring-Up  
- **Task-2:** Simple Memory-Mapped GPIO Output IP  
- **Task-3:** Multi-Register GPIO Control IP  
- **Task-4:** SPI Master IP (Mode 0)

Each task is organized in its own folder with RTL, documentation,
and validation details.

---

## Tools & Environment

- GitHub Codespaces
- RISC-V GCC Toolchain
- Verilog HDL
- Simulation-based validation

---

## Notes

This repository is intended to demonstrate step-by-step learning,
clean RTL design, and proper software–hardware interaction
using memory-mapped I/O.
